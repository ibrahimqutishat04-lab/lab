# 3D Virtual Reality Chemistry Laboratory

An interactive 3D Virtual Reality (VR) chemistry laboratory simulation built in Unity with custom 3D lab equipment modeled in Blender, featuring step-by-step experiment tracking, interactive chemistry quizzes, and real-time chemical reaction simulations.

## Simulated Chemical Reactions & Experiments
- **Beilstein Halogen Flame Test:** Simulates halogen detection by heating a copper wire with real-time flame color transition logic and visual feedback.
- **pH Indicator Testing:** Simulates immersing pH indicator strips/solutions into test liquids with dynamic color-change behavior.
- **CO₂ Gas Evolution (Effervescence):** Simulates carbon dioxide gas bubble release and particle collision interactions during chemical reactions.

## Key Features
- Custom 3D laboratory apparatus and environment modeled and optimized for VR.
- Programmatic step-by-step experiment tracking and guided workflow.
- Interactive in-VR chemistry assessment quizzes.

- **Blender** (3D modeling for lab equipment)
